# 📱 Print Shop PWA - Share Files Feature

## ✨ What's New?

Your print shop website is now a **Progressive Web App (PWA)**! This means:

### 🎯 For iPhone Users (WhatsApp Share Support):

1. **Install the App** (One-time setup):
   - Open the website in Safari on iPhone
   - Tap the "Share" button (square with arrow)
   - Scroll down and tap "Add to Home Screen"
   - Tap "Add"
   - The app icon will appear on your home screen!

2. **Share Files from Any App**:
   - Open WhatsApp, Photos, Files, or any app
   - Select the file(s) you want to print
   - Tap "Share" button
   - **You'll see "PrintShop" in the share menu!**
   - Tap PrintShop
   - Files are automatically added - no need to save first!

### 📱 Features:

- ✅ Works offline (basic functionality)
- ✅ Appears in iOS Share Sheet
- ✅ Share files directly from WhatsApp
- ✅ Share from Photos, Files, Mail, etc.
- ✅ Supports images, PDFs, Word, Excel
- ✅ Responsive design (phone, tablet, laptop)
- ✅ Install banner with easy setup

### 🌐 For Android Users:

1. Open website in Chrome
2. Tap the "Install" button that appears
3. Or tap menu (⋮) → "Install app"
4. Share files from any app → Select PrintShop

### 💻 For Desktop Users:

- Works normally in any browser
- No installation needed
- Full drag-and-drop support

## 📝 Technical Details:

- **Service Worker**: Enables offline support
- **Web Manifest**: Defines app appearance and capabilities
- **Share Target API**: Receives files from other apps
- **Responsive CSS**: Works on all screen sizes

## 🔧 Icon Customization:

The current icons are simple placeholders (purple gradient with "P").

To replace with your custom icons:
1. Create 192x192px and 512x512px PNG images
2. Name them `icon-192.png` and `icon-512.png`
3. Place them in `frontend/public/` folder
4. Delete the `.svg` files

## 🚀 Benefits:

**No App Store needed** - Works directly from the web
**Instant updates** - No need to update from store
**Works everywhere** - iOS, Android, Windows, Mac
**Small size** - Much smaller than native apps
**Direct file sharing** - Just like native apps!
